# Self Learning Platform API

API для платформы самообучения иностранным языкам. Позволяет пользователям изучать слова, проходить уроки, отслеживать прогресс и достигать ежедневных целей.

## 🚀 Технологии

- **Python 3.13** — язык программирования
- **Django 6.0** — веб-фреймворк
- **Django REST Framework** — создание API
- **JWT** — аутентификация
- **PostgreSQL** — база данных
- **OpenAPI (Swagger/ReDoc)** — документация API
- **Pytest** — тестирование
- **CORS** — кросс-доменные запросы

## ✨ Функциональность

### Пользователи
- Регистрация и авторизация (JWT токены)
- Просмотр и редактирование профиля
- Смена роли (для учителей/админов)

### Обучение
- Изучение слов по уровням и темам
- Прохождение уроков (грамматика, лексика)
- Выполнение упражнений с автоматической проверкой
- Отслеживание прогресса (очки, серии, статистика)

### Управление контентом
- Создание и редактирование курсов (только для учителей)
- Добавление уроков, слов, упражнений
- Назначение уровней сложности

### Статистика
- Ежедневная статистика активности
- Достижение целей (минуты, слова, упражнения)
- Серия непрерывных занятий (streak)
